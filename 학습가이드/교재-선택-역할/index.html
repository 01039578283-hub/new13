먼저 확인할 것

이렇게 시작해 보세요.

현재 교재에서 무엇이 해결됐고 무엇이 남았는지 먼저 확인하세요. 새 책은 난도나 권수보다 필요한 설명·연습·재확인의 역할을 채우고 실제 일정 안에서 사용할 수 있는지 비교합니다.

직접 해 보는 순서

  1. 01

    남은 수행 찾기

    개념 설명이 어려운지, 문제 적용이 어려운지, 다른 날 잊는지를 나눕니다. 교재를 다 풀었는지와 독립 수행은 따로 봅니다.

  2. 02

    현재 책의 역할 확인

    설명·예제·연습·복습이 어디에 있는지 확인합니다. 아직 사용하지 않은 부분으로 해결할 수 있는 질문인지 먼저 봅니다.

  3. 03

    새 자료를 작은 범위로 비교

    샘플의 표현과 난도를 직접 보고 학생이 읽거나 풀 수 있는지 확인합니다. 학교 진도와 연결되는 내용도 봅니다.

  4. 04

    사용 계획 정하기

    기존 책과 새 책의 역할을 나누고 중복 과제를 줄입니다. 교사와 필요한 도움 및 확인 방법을 정합니다.

연습을 위해 만든 가상 예시

내 과제에 적용하기 전에, 한 번 해 보세요.

현재 책의 예제는 이해하지만 새로운 숫자의 문제에서 막힙니다. 같은 난도의 책을 더 사면 해결될까요?

생각할 점과 예시 해설 보기

먼저 예제의 이유를 설명하고 작은 변형 문제를 혼자 수행하는 활동을 확인합니다. 필요한 설명이나 연습이 현재 책에 있는지 보고 부족한 역할을 새 자료가 채우는지 비교하세요. 책을 추가한 사실만으로 적용의 어려움이 해결됐다고 볼 수 없습니다.

특정 학생의 실제 경험이나 성적 사례가 아닙니다. 지금 배우는 자료와 수준에 맞춰 바꿔 보세요.

이럴 때는 방법을 조정하세요.

교재 샘플은 실제 학생의 수준과 학교 범위에 맞춰 봅니다. 판매 설명이나 난도 표시만으로 적합성을 확정하지 말고 필요하면 담당 교사에게 자료를 보여 주세요.

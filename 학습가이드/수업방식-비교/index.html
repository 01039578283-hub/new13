먼저 확인할 것

이렇게 시작해 보세요.

학생의 현재 과제 하나를 기준으로 설명을 듣고 연습하고 질문하는 과정이 어떻게 이어지는지 비교하세요. 방식의 이름만으로 효과를 단정하지 말고 실제 진행과 생활 조건을 확인합니다.

직접 해 보는 순서

  1. 01

    공통 비교 과제 준비

    현재 어려운 문제나 글을 고릅니다. 각 수업에 동일한 학습 필요를 질문해야 비교의 기준이 맞습니다.

  2. 02

    설명과 연습 흐름 보기

    설명을 듣는 시간, 학생이 직접 하는 활동, 막혔을 때 질문하는 방법을 확인합니다. 진행 속도가 맞는지도 봅니다.

  3. 03

    환경 조건 확인

    이동, 기기·통신, 필기 공유, 주변 방해 요소를 살펴봅니다. 온라인은 접속 가능 여부와 실제 자료 확인 방법도 확인합니다.

  4. 04

    후속 확인 비교

    수업 뒤 남는 과제와 피드백, 다음 확인 방법을 물어봅니다. 일정과 비용 조건의 확인 여부도 함께 기록합니다.

연습을 위해 만든 가상 예시

내 과제에 적용하기 전에, 한 번 해 보세요.

온라인 수업에서는 화면을 봤지만 풀이를 보여 주지 못했고, 현장 수업에서는 질문을 하지 못했습니다. 무엇을 비교할까요?

생각할 점과 예시 해설 보기

온라인에는 풀이 공유 방식과 기기 환경을, 현장 수업에는 질문을 받는 과정과 학생이 시도한 풀이를 확인하는 방법을 물어봅니다. 장소 자체보다 막힌 과제를 보여 주고 도움을 받는 흐름을 비교합니다. 특정 방식이 항상 우수하다는 결론은 아닙니다.

특정 학생의 실제 경험이나 성적 사례가 아닙니다. 지금 배우는 자료와 수준에 맞춰 바꿔 보세요.

이럴 때는 방법을 조정하세요.

각 방식 안에서도 강사와 운영 구성이 다를 수 있습니다. 실제 해당 수업의 조건을 확인하고 학생이 수행한 결과와 불편한 점을 함께 기록합니다.

먼저 확인할 것

이렇게 시작해 보세요.

학교의 시험 범위를 기준으로 어휘, 문장 구조, 글의 내용, 직접 쓰기를 나눠 확인하세요. 본문 암기 여부만으로 모든 수행을 판단하지 말고 자료마다 필요한 활동을 정합니다.

직접 해 보는 순서

  1. 01

    자료 범위 확보

    교과서 단원과 배부 자료, 수업 설명을 최신 시험 안내와 대조합니다. 없는 자료나 불분명한 범위는 교사에게 확인합니다.

  2. 02

    뜻과 관계 설명

    본문의 중심 내용과 문장 사이의 관계를 말합니다. 모르는 어휘와 구조를 표시하고 근거를 찾아 다시 설명합니다.

  3. 03

    형태와 쓰기 확인

    학교에서 다룬 표현과 문법의 사용 조건을 봅니다. 필요한 문장은 내용을 정하고 도움 없이 쓴 뒤 원문과 대조합니다.

  4. 04

    자료를 섞어 재확인

    이미 연습한 표현을 다른 문장이나 질문에서 확인합니다. 교과서와 프린트에서 공통으로 막히는 수행을 다음 복습으로 정합니다.

연습을 위해 만든 가상 예시

내 과제에 적용하기 전에, 한 번 해 보세요.

교과서 내용은 말할 수 있지만 프린트의 새 문장을 쓰지 못합니다. 무엇을 보완할까요?

생각할 점과 예시 해설 보기

본문 내용을 기억하는 수행은 유지하되, 새 문장의 주어·시간·필수 표현을 정해 직접 쓰는 연습을 추가합니다. 형태의 오류인지 내용 구성이 어려운지 구분하세요. 같은 본문을 더 외우는 것만으로 새 문장 쓰기를 확인할 수는 없습니다.

특정 학생의 실제 경험이나 성적 사례가 아닙니다. 지금 배우는 자료와 수준에 맞춰 바꿔 보세요.

이럴 때는 방법을 조정하세요.

학교별 출제 형식·범위·채점 방식은 다릅니다. 이 글은 특정 학교 시험을 예측하지 않으며 실제 평가 안내와 교사의 피드백을 우선합니다.

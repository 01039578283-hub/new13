먼저 확인할 것

이렇게 시작해 보세요.

AI를 사용하기 전에 학교 과제의 허용 조건과 서비스의 이용 조건을 확인하세요. 자신의 시도와 질문을 먼저 정하고 답의 근거를 교과서·원문과 대조한 뒤 도움 없이 다시 수행합니다.

직접 해 보는 순서

  1. 01

    사용 조건 확인

    학교가 허용한 도구와 사용 범위, 출처 표시 요구를 확인합니다. 이름·학교·성적표 등 개인 자료를 그대로 입력하지 않습니다.

  2. 02

    내 시도부터 작성

    문제에서 이해한 조건과 시도한 풀이를 정리합니다. 완성 답을 달라는 요청보다 막힌 원리나 비교할 설명을 질문합니다.

  3. 03

    원문으로 검증

    제시한 계산을 직접 확인하고 인용·출처는 실제 원문을 열어 봅니다. 존재하지 않는 자료나 단정적인 설명을 그대로 사용하지 않습니다.

  4. 04

    도구 닫고 수행

    같은 개념의 새 과제를 혼자 해 보고 AI 도움과 내 수행을 구분합니다. 과제에는 실제 사용한 도움을 학교 요구에 맞춰 표시합니다.

연습을 위해 만든 가상 예시

내 과제에 적용하기 전에, 한 번 해 보세요.

AI가 “2(x+3)=2x+3”이라고 답했습니다. 설명이 길고 자신 있게 쓰였으니 믿어도 될까요?

생각할 점과 예시 해설 보기

x=1을 대입하면 왼쪽 8, 오른쪽 5로 다릅니다. 분배법칙으로 2x+6이어야 합니다. 답의 말투 대신 직접 계산과 교과서 원리로 확인하고 새 식에서도 혼자 전개해 봅니다. 도구가 제시한 출처도 실제 원문인지 확인해야 합니다.

특정 학생의 실제 경험이나 성적 사례가 아닙니다. 지금 배우는 자료와 수준에 맞춰 바꿔 보세요.

이럴 때는 방법을 조정하세요.

AI의 답은 최신 학교 안내나 교사의 평가 기준을 대신하지 않습니다. 사용이 허용되지 않은 과제에서는 사용하지 않고, 연령·보호자 동의 조건도 실제 서비스에서 확인하세요.

학부모가 함께 도울 때

정답보다 과정에 질문을 건네세요.

“AI가 알려 준 답”과 “네가 직접 확인한 근거”를 나눠 물어보세요. 결과물을 대신 만들게 하기보다 아이의 질문과 검증 과정을 살펴봅니다.

자주 궁금한 질문

AI가 출처를 붙이면 정확한 답인가요?

자료가 실제로 존재하고 해당 주장을 뒷받침하는지 직접 확인해야 합니다. 원문을 열지 못했다면 확인되지 않았다고 남기고 교과서나 교사에게 물어보세요.
